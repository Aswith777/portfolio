# Resume Directory

Place your resume document in this folder.

- Recommended filename: `Chinthapalli_Aswith_Resume.pdf`
- Expected path: `assets/resume/Chinthapalli_Aswith_Resume.pdf`

Once you place your PDF here, open `js/config.js` and set:
```javascript
resume: {
  fileName: "Chinthapalli_Aswith_Resume.pdf",
  filePath: "assets/resume/Chinthapalli_Aswith_Resume.pdf",
  isAvailable: true, // change this to true
}
```
This enables the direct 1-click download button across your portfolio.
